# Research Memory — NotebookLM

## Purpose
Indexes external research sources — PDFs, YouTube videos, industry reports, job market analysis. Agents query this layer when they need domain knowledge that isn't in session memory.

## Sources Currently Indexed
- Builder Buddy product docs
- AI/Automation industry research
- Employment strategy documents
- Remote job market analysis

## How It Works
1. Upload sources to NotebookLM (Google Drive sync → auto-ingested)
2. NotebookLM builds a queryable knowledge base
3. Obsidian vault syncs to Google Drive — NotebookLM pulls from Drive automatically

## Access
- NotebookLM: https://notebooklm.google.com
- Sync path: Obsidian Vault → Google Drive → NotebookLM
