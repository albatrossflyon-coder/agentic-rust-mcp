HOW IT'S USED

Not a website you sign into. A tool your agent calls.

You register this server in an MCP client's config, which spawns it as a subprocess and talks to it over JSON-RPC. From then on, an AI agent can call these tools mid-conversation instead of you checking four dashboards by hand.

01

Register it

Add the compiled binary to Claude Desktop, Claude Code, or any MCP-compatible client's config. It's spawned as a subprocess on demand.

02

Agent calls a tool

Mid-conversation, the agent sends a tools/call JSON-RPC request — e.g. "is my deployment live?" becomes a real agency_pulse call.

03

Real APIs, real answer

The server hits Render, Vercel, Buffer, Firestore, or Gmail directly and returns structured JSON the agent can reason over.
